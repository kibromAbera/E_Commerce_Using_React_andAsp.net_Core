## 🚀 Overview

This repository contains a full-stack e-commerce application designed to provide a seamless online shopping experience. It features a RESTful backend API built with ASP.NET Core and an interactive single-page application (SPA) built with React.

Key architectural concepts implemented in this project:
- **Clean Architecture** & separation of concerns.
- **RESTful API Design** for managing products, categories, cart operations, and user accounts.
- **Component-Driven Frontend Development** using React hooks and state management.

---

## ✨ Features

- **Product Management:** Browse products, view detailed descriptions, and filter by category.
- **Shopping Cart:** Add, update, and remove items with dynamic totals calculations.
- **User Authentication:** Secure login and registration for customers.
- **Responsive UI:** Mobile-first, responsive user interface.

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Axios / Fetch API
- HTML5 / CSS3 / JavaScript (ES6+)

**Backend:**
- ASP.NET Core Web API
- C#
- Entity Framework Core / SQL Database
